# NAKSHATRA HEALTH PROGRAM - COMPLETE API DOCUMENTATION

## **BASE URL**: `http://localhost:8000/api/`
## **Authentication**: Bearer Token (JWT)
## **Default Django Groups**: `Patient`, `Doctor`, `Admin`

---

# **1. AUTHENTICATION ENDPOINTS** (`/auth/`)

## **POST /auth/register**
**Description**: User registration (Patient, Doctor, or Admin)

**Payload**:
```json
{
  "email": "sarah@example.com",
  "password": "SecurePass123!",
  "full_name": "Sarah Khan",
  "phone": "+91-9876543210",
  "role": "Patient"
}
```

**Response (201 Created)**:
```json
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "id": 1,
    "email": "sarah@example.com",
    "full_name": "Sarah Khan",
    "role": "Patient",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

```json
  "success": false,
  "error": "Error code",
  "message": "Human-readable error message",
  "details": {
    "field_name": "Validation error details"
  }
}
```

### **Common Error Responses**:
- **400 Bad Request**: Invalid payload
- **401 Unauthorized**: Missing/invalid token
- **403 Forbidden**: User lacks permission
- **404 Not Found**: Resource not found
- **500 Internal Server Error**: Server error

---

## **Authentication Header**
All requests except login/register/public endpoints:
```
Authorization: Bearer <JWT_TOKEN>
```
